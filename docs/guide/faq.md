# FAQ

??? question "Will RetroForge erase Android?"

    No. RetroForge runs from an SD card and does not touch Android. Remove the card and the device boots Android as before. The optional internal storage install is the only thing that changes Android, and it asks first.

??? question "Do I need OpenABL?"

    Yes. The stock bootloader on these handhelds will not start RetroForge. See [What you need](requirements.md).

??? question "Is there a different image for each device?"

    No. One image serves every [supported device](../devices/index.md). It recognises the board it is running on and configures itself.

??? question "Does it run Android apps?"

    No. RetroForge is a focused retro emulation system. It has no Android container.
