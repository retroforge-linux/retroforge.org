## Is my device missing?

RetroForge supports Qualcomm Snapdragon handhelds only. If yours is one and it is not listed, ask on [Discord](https://discord.gg/ZfgXY3W2F9), or see [Adding a board](../developers/adding-a-board.md) if you want to bring it up yourself.
